# Changelog

## v0.1.0-beta — 2026-11-11

- Initial community release candidate for Windows Codex Desktop + Responses API gateways.
- Added isolated second-profile installer and MSIX launcher (unofficial).
- Added opt-in main-provider switch with timestamped config backups and restore.
- Added DPAPI-backed API key storage and basic Responses API smoke test.
- Added Thai and English documentation, architecture diagrams, troubleshooting, and security notes.
- Added static PowerShell checks and GitHub Release workflow.

**Known limitations:** GUI/MSIX method is version-sensitive; generic scripts are not yet verified end-to-end on all Windows configurations. A basic API test does not prove streaming or tool calling.
